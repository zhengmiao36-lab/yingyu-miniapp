# 沉浸式剧场微信小程序原型

这是一个基于公开界面观察重新实现的原生微信小程序原型，不是原小程序源码，也不包含原品牌、海报、演员照片、账号或后端数据。

## 已实现

- 卡司排班、周切换、往期排班展开和购票确认流程
- 三列演员阵容和演员详情、角色积分、近期排班
- 卡司积分榜与会员消费积分榜切换
- 紧凑型门店商城、商品订单与本地持久化
- 确认订单、我的订单、数字核销凭证和动态二维码预留
- 体验账号、昵称修改、头像主题切换和个人菜单

## 本地运行

1. 安装并打开微信开发者工具。
2. 导入本目录，并使用正式小程序 AppID；不要选择测试号。
3. 编译并使用模拟器或预览二维码测试。

## 接入正式服务前

- 用自有或已授权的海报、演员照片替换代码化占位视觉。
- 将 `utils/mock-data.js` 替换为后端接口或云开发数据。
- 接入微信登录、手机号授权、票务订单、支付、退款和核销流程。
- 补齐隐私保护指引、服务类目资质、服务器域名及备案要求。

微信支付和门店核销的接口契约见 `docs/wechat-pay-integration.md`。
